# Guessy-Integer-Challenge
Guessy Integer Challenge is a command-line number guessing game. The player chooses an easy, medium, or hard difficulty, which gives them 10, 7, or 5 guesses to find a random number between 1 and 100. The game gives “too high” or “too low” hints, celebrates a win with a confetti animation, and shows a game-over animation after a loss.
